# Clip Autopilot Worker

Kostenloser GitHub-Actions-Worker für die Clip-Autopilot-Webseite.

- Quelle: YouTube-Link
- Engine: Chopify (Open Source)
- TikTok-Clips: ca. 55–70 Sekunden
- YouTube Shorts: ca. 20–40 Sekunden
- Format: 9:16
- Untertitel, Straffung und Loudness-Normalisierung

Der Workflow wird von der Clip-Autopilot-Webseite gestartet und veröffentlicht die fertigen MP4-Dateien als GitHub-Release-Assets.
